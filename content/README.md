# Nusaiba's bookshelf content

Each folder is one book. Create an article in the Writer's Desk, download its `.md` file, and upload it into the matching folder. GitHub Actions rebuilds `library-content.js` and publishes the page automatically.

- `building` — projects and problem-solving
- `understanding` — faith, people and ideas
- `remembering` — Bangladesh, history and family
- `reciting` — বাংলা আবৃত্তি; write these pages in Bangla
- `reading` — books and lessons
- `making` — crafts and experiments
- `cooking` — recipes and food memories
- `becoming` — personal growth and unfinished learning
